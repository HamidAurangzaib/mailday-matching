**Feature 2 — Pack Delivery Tracker**

Add a Pack Delivery Tracker to the left navigation under the Operations section. Admin and VA can both see this view.

**New Supabase table — Pack Delivery Log:**

id, month_name, month_number, year, total_active_members_at_send, core_members_count, minis_members_count, homeschool_core_count, homeschool_minis_count, delivery_emails_sent, delivery_emails_failed, delivery_emails_manually_resent, confirmation_status (Pending / Sent / Partial / Confirmed), confirmed_by, confirmed_date, notes, created_date

**New Supabase table — Pack Delivery Failures:**

id, pack_delivery_log_id (foreign key), parent_id (foreign key), child_id (foreign key), failure_reason, resolved (boolean), resolved_date, resolved_by, resolution_notes, created_date

**How the tracker works:**

On the first of every month the app automatically creates a new Pack Delivery Log record for the current month. It populates month name, month number, year, and the current active member counts by tier. Status is set to Pending.

When the Klaviyo pack delivery webhook fires for each member the app increments delivery_emails_sent on the current month's log record. If a webhook returns a failure the app increments delivery_emails_failed, creates a record in Pack Delivery Failures linked to the affected parent and child, and surfaces it as a pending action on the Operations Dashboard and in the Action Items queue.

Admin or VA can manually mark individual failures as resolved — they select the failure record, click Mark Resolved, enter resolution notes, and the resolved field sets to true. When all failures for a month are resolved the month's status updates automatically from Partial to Confirmed.

Admin can manually update the confirmation status at any time and add notes — for example if pack delivery happened outside the normal Klaviyo flow.

**The Pack Delivery Tracker view:**

Current month row displayed prominently at the top with full status — total members, sent count, failed count, resolved count, current status, days since send.

All previous months below in reverse chronological order — most recent first.

Each row is expandable — clicking it shows the full breakdown by tier and a list of any failure records for that month with their resolution status.

Filter by year. Filter by status. Export full log as CSV. Export failures only as CSV.

Failure detail panel — clicking any failure record opens a side panel showing the parent name, child name, tier, failure reason, resolution status, and full resolution notes. Mark Resolved button available directly in the panel.

At the top of the Pack Delivery Tracker show a summary header: total months tracked, total emails sent to date, total failures to date, overall delivery success rate as a percentage.
